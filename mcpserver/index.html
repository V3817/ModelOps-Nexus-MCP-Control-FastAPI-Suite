API Documentation

The weather service provides the following API endpoints:

  • /tool/get_alerts?state=CA - Get weather alerts for a state
  • /tool/get_forecast?latitude=37.7749&longitude=-122.4194 - Get forecast for coordinates

You can also use the SSE endpoint for real-time updates:

  • /events - Server-Sent Events endpoint
